# SDF.R V15.9.8.1 Mac/Linux テスト版 テスター向け案内ガイド

本テスト版（V15.9.8.1）は、Windows通常版をベースに、macOS（Apple Silicon）およびLinux向けに移植した初期テストビルドです。
テスターの皆様には、以下のガイドラインに沿ってインストール・動作検証を行っていただき、不具合や動作状況の報告をお願い申し上げます。

---

## 1. テストでの検証項目（確認するべきこと）

アドオンの基本機能が各OS環境で正常に動作するか、以下のステップに沿ってご確認ください。

1. **アドオンのインストールと有効化**
   - 配布されたZIPファイル（`SDF_R_15_9_8_1_MAC.zip` または `SDF_R_15_9_8_1_LINUX.zip`）をそのまま Blender でインストールします。
   - アドオンのチェックボックスをONにした際、初期化エラーや警告なしで有効化できるか。
2. **初期化とエンジン起動の確認**
   - Blenderのコンソール（システムコンソール）を開き、以下のログが出力されているか確認します。
     - `SDF.R: --- Initializing GPU Engine (V15.9.8.1) ---`
     - `SDF.R: GPU Engine Ready!`
3. **基本メッシュ生成とリアルタイム変形**
   - 3Dビューポート上でSDFメッシュを新規作成します。
   - プリミティブ（Sphere、Box、Torus等）を追加し、移動・回転・スケールを行った際にリアルタイムでメッシュが滑らかに変形するか。
   - スムーズ合成（Smoothness）の値を変更した際に、メッシュの境界が崩れたり、穴が開いたりしないか。
4. **高解像度での耐久性・安定性**
   - 解像度（Resolution）を `128` や `256` に引き上げた際に、極端な処理のフリーズや Blender の強制終了（クラッシュ）が起きないか。
5. **アンインストール処理**
   - アドオンのチェックボックスをOFFにし、アドオン自体を「削除」した際に、正しくアンインストールが行われるか。

## 2. エラー発生時の自己対処法（よくある問題と解決策）

### macOS特有：Gatekeeper（実行ブロック）の回避
GitHub Actions（CI環境）でビルドされた macOS 用のバイナリ（`rust_gpu_sdf.so`）はデジタル署名がされていないため、初回有効化時に「開発元を確認できないため開けません」という警告ダイアログが表示されて有効化がブロックされる場合があります。

**【回避手順】**
1. 警告ダイアログが出たら、一度「キャンセル」を押します。
2. macOSの「システム設定」＞「プライバシーとセキュリティ」を開きます。
3. 画面下部に「"rust_gpu_sdf.so" は開発元を確認できないため、使用がブロックされました」と表示されていることを確認し、**「このまま開く」**をクリックします。
4. Blenderに戻り、再度アドオンのチェックボックスをONにします。

### Pythonのインポートエラー（パッケージ名解決の不具合）
古いテスト版では、Blenderがアドオンを一時ロードする際に `RuntimeError: attempted relative import with no known parent package` などのエラーが発生することがありました。本バージョンではフォールバックが実装されていますが、万が一有効化できない場合は、エラーログ（コンソール）の確認をお願いします。

### GPU初期化エラー
SDF.R は WebGPU（wgpu）を用いてGPU上でメッシュ計算を行います。Linux等でドライバが古い、または適切なGPUが認識されていない場合、`Parent device is lost` や `wgpu Validation Error` などのエラーが発生し、メッシュが描画されないか Blender がフリーズする場合があります。
