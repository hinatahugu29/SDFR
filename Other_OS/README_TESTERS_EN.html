SDF.R Mac/Linux Tester Guide

An initial test build compiled for macOS and Linux, based on the Windows version.

1. Testing Verification Items (What to Check)

  • 1
    Add-on Installation & Activation
    Install the provided ZIP file (without extracting it) in Blender. Check if you can activate it by checking the checkbox without getting any error dialogs.
  • 2
    Verify Engine Initialization Logs
    Open the Blender system console (or terminal) and confirm if the following logs are printed:
    SDF.R: --- Initializing GPU Engine (V15.9.8.1) ---
    SDF.R: GPU Engine Ready!
  • 3
    Basic Mesh Generation & Real-time Sync
    Create a new SDF mesh in the viewport. Add shapes (Sphere, Box, etc.) and check if they deform and blend smoothly in real-time. Ensure changing the Smoothness value doesn't cause mesh tearing.
  • 4
    Resolution Durability Test
    Increase the Resolution to 128 or 256. Make sure it doesn't freeze the system permanently or crash Blender.
  • 5
    Deactivation & Uninstallation
    Ensure you can disable and completely remove the add-on cleanly.

2. Troubleshooting (Common Issues)

macOS Specific: Bypassing Gatekeeper (Block on Load) ▼

Since the macOS binary (rust_gpu_sdf.so) is automatically compiled in GitHub Actions (a CI environment), it lacks an Apple developer signature. macOS security features may prevent it from loading initially.

【Bypass Steps】

1. When the security block popup appears, click "Cancel".

2. Open macOS "System Settings" > "Privacy & Security".

3. Scroll down to find the message: "rust_gpu_sdf.so" was blocked from use... and click "Open Anyway".

4. Go back to Blender and enable the add-on checkbox again.

Python Import / Circular Import Errors ▼

If Blender loads the add-on from a temporary installation folder, Python boundary package detection can sometimes fail, leading to errors like attempted relative import with no known parent package. While this build has a fallback to resolve this, please report details if you still see issues.

GPU / WebGPU Startup Failures ▼

SDF.R relies on WebGPU (wgpu) for computing meshes on the GPU. On Linux or older devices, if graphics drivers are outdated or initialization fails, Blender may freeze or crash. Please share your OS version and GPU model in such cases.

💡 How to Open Blender System Console

macOS / Linux: You must launch Blender from your Terminal application. Open terminal, drag and drop the Blender app executable (e.g., /Applications/Blender.app/Contents/MacOS/Blender), and press enter. Any crash or error logs will print directly to the terminal screen in real-time.
