# SDF.R V16.0.4 パフォーマンス ＆ プレビュー品質チューニングガイド

本アドオンでは、操作時の「軽さ（フレームレート/FPS）」と「プレビューの見た目（輪郭の黒ずみ/ディテール）」のバランスをとるため、操作状態に応じて計算負荷（レイマーチのステップ数）を動的に抑える仕組みを導入しています。

今後、PCスペックや好みに合わせてこれらのバランスを再調整したい場合は、以下の定数を変更してください。

---

## 調整対象のファイル
調整を行うには、アドオンフォルダ内の以下のファイルをテキストエディタ等で開きます。

**[rust_gpu_sdf_addon/handlers.py](file:///e:/blender_addon/外部テスト/Rust-GPU-SDF-V16.0.4/rust_gpu_sdf_addon/handlers.py#L32-L37)** 

---

## 調整可能なパラメータ（定数）
ファイルの **32行目〜37行目付近** に、以下の定数が定義されています。

```python
_INTERACTIVE_STEP_CAP = 160  # (以前の互換用制限値)
_CAMERA_MOVING_STEP_CAP = 64  # カメラ移動中の最大ステップ数
_TRANSFORM_STEP_CAP = 128     # オブジェクト操作中の最大ステップ数
_INTERACTION_IDLE_SEC = 0.2   # 静止後に高品質へ復帰するまでの待機時間（秒）
```

### 1. カメラ操作中のステップ数制限 (`_CAMERA_MOVING_STEP_CAP`)
カメラを回転（Orbit）、パン（Pan）、ズームしている間の最大計算ステップ数です。
* **小さくする（例: `48`〜`64`）**: カメラの回転が極めて軽快になりますが、オブジェクトの「縁（輪郭）」や斜めの部分に黒い欠落（歩数不足）が出やすくなります。
* **大きくする（例: `80`〜`96`）**: 輪郭の黒い欠落がほとんど消えて綺麗な見た目になりますが、プリミティブが多いシーンではカメラ回転時のFPSがわずかに低下します。
* **推奨の調整**: 軽さと見た目のバランスをとる場合は **`80`** または **`96`** に設定してください。

### 2. オブジェクト操作中のステップ数制限 (`_TRANSFORM_STEP_CAP`)
オブジェクトを `G` キー（移動）、`R` キー（回転）、`S` キー（拡縮）でドラッグしている間の最大計算ステップ数です。
* **推奨の範囲**: **`96`** 〜 **`160`**
* 移動中はオブジェクトのディテールを確認しやすいため、カメラ移動時（`_CAMERA_MOVING_STEP_CAP`）よりも少し大きめの値を設定するのが最適です。

### 3. 高品質への復帰時間 (`_INTERACTION_IDLE_SEC`)
カメラ操作やオブジェクト操作を止めて（静止して）から、本来のクリアな高品質プレビュー（LOW/MID/HIGH に応じた 128〜512 ステップ）に復帰するまでの秒数です。
* **推奨の範囲**: **`0.1`** 〜 **`0.3`** 秒
* 操作を止めた後、どれくらい素早く「カクッ」と高品質に戻すかの感覚を調整できます。

## 変更の適用方法
1. 上記の定数を書き換えてファイルを保存します。
2. Blenderを再起動するか、Blenderのプリファレンスで「Mesh: SDF.R」アドオンのチェックを一度外して、再度有効化（リロード）すると変更が反映されます。
