# SDF.R Standalone - 開発ロードマップ (Roadmap)

本ドキュメントは、SDF (Signed Distance Field) を用いた次世代モデリングエンジン「SDF.R Standalone」の今後の開発計画をまとめたものです。

---

## 🚀 フェーズ 1: 基礎機能の解放 (現行エンジン能力の最大化)
現状、シェーダー（WGSL）側には実装されているがUIから操作できない機能を順次開放します。

- [ ] **プリミティブの拡充**: 
    - [x] トーラス (Torus), 円柱 (Cylinder), 円錐 (Cone) の追加
    - [x] 角丸ボックス (Rounded Box), カプセル (Capsule) の追加
    - [x] 形状固有パラメータ（半径、高さ、角数など）のUI調整機能
- [ ] **レイアウト（複製・配置）システムのUI化**:
    - [x] ミラーリング (Mirror) - X, Y, Z軸
    - [x] グリッド複製 (Grid Repeat)
    - [x] 放射状・螺旋配置 (Radial/Spiral Patterns)
- [ ] **デフォーマー（変形）の整理**:
    - [x] ねじり (Twist), 曲げ (Bend), テーパー (Taper) の複数スロット化
    - [x] シェル (Shell/Hollow) 機能の追加

## 🛠 フェーズ 2: モデリング体験の向上 (UX/ワークフロー)
本格的な造形を行うためのエディタ機能を強化します。

- [ ] **シーン管理機能**:
    - [ ] オブジェクトの複製 (Duplicate) と 削除 (Delete) のショートカット対応
    - [ ] 基本的な Undo/Redo システムの導入
    - [ ] オブジェクト名のリネーム機能
- [ ] **ファイル入出力 (I/O)**:
    - [ ] シーンの JSON 形式での保存・読み込み
    - [ ] メッシュ焼き出し (Baking): Marching Cubes / Dual Contouring による STL/OBJ 出力
- [ ] **ギズモ (Gizmo) の導入**:
    - [ ] スライダーだけでなく、ビューポート上で直接移動・回転・拡縮ができる 3D ギズモの実装

## ✨ フェーズ 3: 視覚効果とマテリアル (レンダリング品質)
プレビュー品質を向上させ、完成イメージを掴みやすくします。

- [ ] **高度なマテリアル設定**:
    - [ ] トリプラナーマッピング (Triplanar Mapping) によるテクスチャ適用
    - [ ] 複数のプロシージャルノイズ（Voronoi, Perlin）の選択
- [ ] **ライティング & ポストプロセス**:
    - [ ] 環境マップ (HDRI/IBL) によるリアルな反射
    - [ ] アンビエントオクルージョン (AO) の実装
    - [ ] 被写界深度 (DOF) や ブルーム (Bloom) 効果

## 🌌 フェーズ 4: 次世代機能 (更なる展望)
従来の CAD や ポリゴンモデラーを超えた機能を目指します。

- [ ] **ノードベース・エディタ**:
    - [ ] 形状の組み合わせをノードで構築し、非破壊な複雑なブーリアンを実現
- [ ] **AI アシスト・モデリング**:
    - [ ] プロンプトからの SDF 形状生成、または形状の最適化提案
- [ ] **リアルタイム物理シミュレーション**:
    - [ ] SDF の特性を活かした、高速で安定した衝突判定と流体シミュレーション

---

## 📈 現在のステータス: V0.1.0 (Standalone Prototype)
- [x] Rust + WGPU による高速描画基盤
- [x] 基本的なブーリアン（Union/Subtract/Intersect）
- [x] エミッション、カラーインフルエンス等のマテリアル制御
- [x] パン/オービットカメラ操作
