SDF.R V16.2.2 UI / Command Inventory

Target: Rust-GPU-SDF / SDF.R V16.2.2 | Created: 2026-07-19 (V16.2.1 update: 2026-09-09 / V16.2.2 update: 2026-09-12) | Purpose: Inventory of UI buttons and major controls

How to read the update categories: Mesh Rebuild re-evaluates the SDF and rebuilds the result mesh; Lightweight Update only updates existing mesh attributes or display state; Display / Management covers mainly UI, selection, visibility, and management operations.

Important note on color updates: Apply Color All applies a single color to the entire result, so it can use a lightweight update. In contrast, the color swatches in the Stack and individual Color values affect color blending, so a Mesh Rebuild is required to preserve correct colors at boundaries.

8-B. Tree Reference (Added in V16.2.1)

SDF_TreeRef_NNN appears when an Empty with this name is selected. When the scene has multiple trees, an add button is shown.

Display Name Type Description Update Notes
Add Tree Reference Button sdf.add_tree_ref Adds a reference Empty to the Stack for incorporating another tree. Mesh Rebuild When created, it is placed above the referenced target. If not moved, their positions match.
Tree Reference tree_ref_obj Selects the tree (output object) to incorporate. Mesh Rebuild Self-references and mutual references are ignored to prevent infinite loops.
Mode Enum tree_ref_mode Blend (combine) / Subtract (subtract). Mesh Rebuild Blend is exact. Subtract is exact when the referenced tree uses only Union; if it uses Subtract/Intersect internally, the result is approximate.
Smoothness Numeric Blend radius used when incorporating the referenced tree. Mesh Rebuild —
Profile / Chamfer Enum / Numeric Blend profile used in Blend mode. Mesh Rebuild Shown only when Mode is Blend.
(Warning) Information Shown when the referenced tree uses Subtract/Intersect internally. Display / Management Shown only when Mode is Subtract.

Nested references are supported only one level deep. If the referenced tree itself references another tree, that additional reference is not followed. Editing the referenced tree also automatically updates the incorporating tree (included in the state hash).

10. Math Field-Specific Commands

Display Name Type Description Update Notes
Formula Selection Selects Gyroid / Schwarz P / Schwarz D. Mesh Rebuild TPMS-type mathematical field formulas.

Boundary Selection Selects boundary behavior such as Fade / Open / Box Clip. Mesh Rebuild Affects the appearance of the boundary edges.

Phase Numeric Phase-shifts the field period. Mesh Rebuild Adjusts the positions of holes and ridges.
Axis X/Y/Z Numeric Adjusts field density along each axis. Mesh Rebuild Important for appearance adjustment under non-uniform scaling.
Auto Match Scale Button sdf.match_math_field_axis_to_scale Copies the absolute Object Scale values to Axis X/Y/Z. Mesh Rebuild Use this to keep world-space density consistent after scaling. Values are clamped from 0.05 to 8.0.
Scale / Thickness / Bias / Extent Numeric Sets Math Field cell density, thickness, offset, and extent. Mesh Rebuild Basic parameters shared by all formulas.

11. Layout (Instancing)

Display Name Type Description Update Notes
Mirror Toggle Mirrors the selected primitive. Mesh Rebuild Uses X/Y/Z axis selection and Offset.
Mirror Blend Numeric mirror_blend (V16.2.1) Rounds the seam between mirrored copies.Default: 0.0.V16.2.2: the panel warns when Blend goes past twice the Offset, where the whole shape swells rather than just the seam (capped at 2.0, so it cannot be reached at an Offset of 1.0 or more). Mesh Rebuild When set to 0, it uses exactly the same path as before. At >0, both sides are evaluated separately, so evaluation cost is about 1.7× for one axis and doubles with each additional axis. The primitive Smoothness does not affect this seam, so use this setting when you want it rounded. Radial / Grid are not supported. Preview is approximate.

Spiral Toggle Duplicates in a spiral. Mesh Rebuild Pitch controls the vertical direction.
Grid Toggle Duplicates in a grid. Mesh Rebuild Sets Count X/Y/Z and Spacing X/Y/Z.
Jitter Toggle Adds random variation to the layout. Mesh Rebuild Sets Seed / Strength.
Rotation (Indiv & Accum) Angle Sets individual and accumulated rotation. Mesh Rebuild Used to orient Radial / Spiral / Grid layouts.
