0. SDF.R モデリングの基本原則と作業フロー

SDF.R（Signed Distance Field Renderer）は、従来のポリゴン押し出しモデリングとは異なり、「プリミティブを配置し、ブーリアンで足し引きし、滑らかに繋ぐ（Smooth Blend）」 という数学的・直感的なモデリング手法を採用しています。

[1. ラフ造形] ───> [2. 接続・プロファイル] ───> [3. 階層・変形・配置] ───> [4. 質感・仕上げ] ───> [5. 保存・確定] 基本形状の配置 ギズモで角丸/スムーズ Divider/参照/Mirror/Deform 色・Roughness統一 Snapshot / Finalize
💡 V17.0.1 の操作の核: 「ビューポートギズモ」と「サイドパネル」の役割分担
・3Dビューポート・ギズモ（直感操作）: プリミティブを選択すると矢印ギズモやボタンスイッチが表示されます。寸法（半径・高さ）、角丸め（Fillet）、肉厚（Shell）、ブレンド半径（Smoothness）、ブーリアン演算（Union/Subtract/Intersect）、エッジプロファイル（Round/Chamfer等）は、画面を見ながら直接ドラッグ＆クリックで素早く調整できます。
・サイドパネル（詳細・全体設定）: 階層管理（The Stack）、解像度・ボクセル設定（Output & Quality）、事後スムージング、マルチツリー管理、マテリアル全体適用などはサイドパネルから操作します。

【基礎編】基本作業パターン

パターン1: 【超速入門】ギズモで操る直感モデリング（結合・穴あけ・フィレット）

目的: 最短でSDFの基本原理（足す・引く・繋ぐ）と、V17ビューポートギズモの快適な操作感を体得する。
想定成果物: 角が丸められ、滑らかな貫通穴が開いた機械的ブロックパーツ。

[初期Box] ──(橙矢印ドラッグ)──> [角丸Box] ──(Cylinder重ね+減算ボタン)──> [穴あきブロック] ──(紫矢印ドラッグ)──> [なめらかな穴の完成]
  1. シーン初期化: 3DビューポートのNパネル SDF.R タブを開き、Initialize SDF System ボタンをクリックします。デフォルトの球体が配置され、ライブメッシュが表示されます。
  2. 直方体の配置: パネルの Add New Primitives から Box をクリックします。初期球体が不要な場合はStackリストでSphereを選んで − ボタンで削除します。
  3. ギズモで寸法とフィレット（角丸）を直感調整: 選択中のBoxの周囲にオレンジ色の矢印ギズモが表示されます。オレンジ矢印を外側にドラッグすると、直方体の角が滑らかなフィレット（角丸）に変化します。
  4. 円柱による穴あけ（Subtract）: Add New Primitives から Cylinder を追加します。Blenderの移動（G キー）でBoxの中央を貫通するように配置します。ビューポート上に表示されている **Operationボタン** から Subtract をクリックすると、瞬時に穴が開きます。
  5. ギズモで穴の馴染みを調整: Cylinderの周囲にある**マゼンタ色矢印ギズモ（Smoothness）** を外側に少しドラッグすると、穴の境界が柔らかくブレンドされ、工業製品の鋳造・プレス加工のような自然なエッジが生まれます。
ポイント: サイドパネルの数値スライダーを行き来することなく、ビューポート上のドラッグ＆クリックだけでモデリングが完結します。

パターン2: 【有機体・クリーチャー造形】スムーズブレンドとカラー混色

目的: スカルプトのように滑らかに溶け合う有機的なキャラクター、頭部、液体、筋肉などの素体を作る。
想定成果物: 複数パーツが有機的に融着し、部位ごとに美しいグラデーション混色を持つクリーチャーヘッド素体。

  1. 中心核の配置: Sphere を配置し、中心の核とします。
  2. 手足・突起の追加と引き伸ばし: Ellipsoid（楕円体）を追加します。選択すると現れる 赤・緑・青の3軸矢印ギズモ を個別にドラッグして、前後や上下に引き伸ばし、頭部や顎の形状を作ります。同様に Capsule を追加し、首や角のベースとして配置します。
  3. Smoothnessを大きく引き上げて有機的に融着: すべてのプリミティブの Operation を Union のままにし、各パーツの マゼンタ矢印ギズモ（Smoothness） を大きく（0.4 〜 0.8 程度）ドラッグします。パーツ同士の境界線が完全に消え、筋肉や粘土のように滑らかに融着します。
  4. 部位ごとのカラー設定とグラデーション混色の確認: サイドパネルの Primitive Settings > Color で、頭部をブルー、突起部をオレンジなど個別に指定します。GPUエンジンがブレンド幅に応じて2色を自動的にグラデーション混色（カラーブレンディング）します。
  5. 全体の質感統一（仕上げ）: 形状が決まったら、サイドパネルの Material > Apply Color To All や Apply Material To All を実行し、作品全体に統一したトーンと光沢を与えます。

パターン3: 【ハードサーフェス・メカ部品】面取りプロファイルと中空シェル

目的: 工業デザイン、メカ外装、電子機器ケースなど、シャープな角・面取り（Chamfer）と中空（Shell）を持つハードサーフェスパーツを作る。
想定成果物: 外側が面取りされ、内部が均一な肉厚で中空化されたメカニカルカバー。

  1. 外装ベース形状の作成: Hex Prism（六角柱）または Box を追加します。
  2. エッジプロファイルの切り替え（面取り Chamfer）: ビューポート上の Edge Profileボタン から Chamfer をクリックします。オレンジ色の矢印ギズモ（Fillet）をドラッグすると、直線的な45度C面取りとして斜めに削り落とされます。
  3. シアン矢印ギズモで中空（シェル）構造にする: プリミティブの周囲にある シアン色の矢印ギズモ（Shell Thickness） を内側方向へドラッグします。ソリッドな塊だったHex Prismの内部がくり抜かれ、指定した肉厚（例: 2mm）の薄肉中空ケースに変化します。
  4. 内部ボス（ネジ受け柱）の配置: Cylinder を追加し、ケースの底面内側に立てるように配置します。Operationは Union、Smoothnessを極小（0.05 程度）にすると、ケース内壁とわずかなフィレットで強固に接合されます。
  5. 通気スリットの削り出し: 薄い Box を追加し、Operationを Subtract に設定してケース側面に配置すれば、シャープな通気口スリットが開孔されます。

パターン4: 【対称・幾何学レイアウト】ミラー対称とラジアル配列

目的: キャラクターや乗り物の完全な左右対称配置、およびホイールやファン、装飾などの円周パターンを効率よく作成する。
想定成果物: 左右対称のビークルボディと、放射状に等間隔配置されたホイールスポーク。

  1. 左右対称モデリング（Mirror Mode）: パーツ（例: 腕やジェットエンジン用のCylinder）を作成し、X軸のプラス側（右手側）へ配置します。サイドパネルの Layout (Instancing) で Mirror Mode を X に設定します。反対側にリアルタイムで完全な対称パーツが出現し、元のパーツの編集に完全追従します。
  2. ホイール・ギアの円周配置（Radial Array）: 別のCylinderを中心 (0, 0, 0) に配置し、スポーク（棒状パーツ）として細長いBoxを配置します。Boxを選択し、Radial Array Count を 6（または8）に設定すると、中心軸の周りに6本のスポークが60度間隔で放射状に複製配置されます。
  3. 親パーツのTransformによる全体の微調整: 親Boxをスケールまたは回転させると、6本のスポーク全体が連動して変形・回転します。
💡 メリット: SDFの空間座標を数学的に折り返すため、メッシュポリゴンを増やさず極めて軽量・高精度です。

【応用編】アドバンスド制作パターン

パターン5: 【マルチツリー＆ツリー参照】部品の独立管理とアセンブリ構築

目的: 互いに溶け合わない独立パーツ（ロボットの手足、車両のタイヤ、眼球とまぶた等）を別ツリーとして制作し、メインモデルに参照配置して組み立てる。
想定成果物: ボディ、タイヤ、関節がそれぞれ独立したメッシュとして存在し、干渉部が溶け合わない高精度メカアセンブリ。

[Tree 0: Body (メイン車体)] ▲ └── [Tree Reference Empty] ──(参照)──> [Tree 1: Tire (独立したタイヤツリー)]
  1. メインツリー（車体）の制作: 初期ツリー（Tree_0）で車体のメインフレームをモデリングします。
  2. 新規SDFツリー（タイヤ）の立ち上げ: パネル最上部 0. Tree の ＋ ボタン（Add Tree）をクリックし、新しい独立ツリー（Tree_1）を作成します。ここでタイヤ専用のモデリング（ホイール、ハブ、トレッド等）を作り込みます。
  3. Tree Reference（ツリー参照）によるアセンブリ配置: Tree ドロップダウンを Tree_0 に戻し、8-B. Tree Reference の Add Tree Reference をクリックします。車体ツリー内に参照Emptyが作成され、プロパティ Referenced Tree で Tree_1 を選択します。
  4. 参照Emptyの配置・拡縮・複製: 通常のBlenderオブジェクトと同様に G（移動）、R（回転）、S（拡縮）で前輪位置へ移動させ、さらに Shift + D で複製して後輪位置へ配置します。
  5. 溶け合わない独立メッシュとしての利点: 通常のSDFでは車体とタイヤが近接すると勝手に溶け合ってしまいますが、別ツリーとして管理されているため、境界が溶け合わずシャープな隙間を保ったまま同居します。

パターン6: 【Collection Divider】局所ブーリアンと階層カプセル化

目的: 複雑なモデルにおいて、「あるグループ内だけでブーリアン完結させ、他の部分に影響を与えない（局所演算）」設計を行う。
想定成果物: 胴体に干渉することなく、腕パーツの内部だけでくり抜きやブレンドが完結する階層モデリング。

  1. スタックの構造理解: SDF.Rの The Stack は上から下へと順番にブーリアン評価されます。そのままだと下部にあるSubtractプリミティブが上部の胴体まで削ってしまう事故が起こり得ます。
  2. Collection Divider（境界線）の挿入: 腕パーツ群を作成する直前の位置で、The Stack の ＋（Add Collection Divider）をクリックします。スタック内にフォルダアイコンのDivider項目が挿入され、名前を Arm_Group に変更します。
  3. グループ内のパーツ構築: 腕用パーツを追加し、スタック上でDividerの下に配置します。このグループ内で行われる Subtract や大きな Smoothness は、Dividerの内側だけで評価されます。
  4. グループ全体のメインツリーへの結合設定: Divider自体の Operation（通常は Union）や Smoothness を設定することで、完成した腕グループが胴体に対して指定のスムーズ量で一体化します。

パターン7: 【Math Field幾何学装飾】多孔質構造と幾何学パターンのくり抜き

目的: 通常のポリゴン操作では不可能な数学的陰関数（Gyroid曲面、Clebsch曲面など）を呼び出し、モデルの表面や内部に複雑な格子・装飾パターンを埋め込む。
想定成果物: 外殻の一部がジャイロイド（多孔質ラティス構造）で軽量化・装飾されたSF風ドローンパーツ。

  1. ベース形状の用意: ベースとなる Box または Sphere を配置します。
  2. Math Fieldの追加とプリセット選択: Add New Primitives から Math Field を追加し、11. Math Field 専用コマンド で Math Preset から Gyroid を選択して Compile Math Expression をクリックします。
  3. 交差演算（Intersect）によるくり抜き: Math FieldのOperationを Intersect（交差）に切り替えると、ベース形状の体積内部だけに美しい周期的な波状多孔質構造が生成されます。
  4. 外枠（リム）との組み合わせ: 同じサイズのBoxをもう1つ用意し、中空シェル化（Shell Thicknessを適用）して Union で重ねると、「外周はソリッドフレーム、内部はジャイロイド格子」という3Dプリント実用品のような高機能パーツが完成します。

パターン8: 【Deform Stack変形】プロシージャルなねじれ・曲げ・先細り

目的: プリミティブに対して非破壊な変形モディファイア（Elongate / Twist / Bend / Taper / Noise）を複数重ねがけし、ドリル、ツノ、爪、触手などの複雑な歪み形状を作成する。
想定成果物: 螺旋状にねじれながら先端に向かって鋭利に先細るクリーチャーのツノ／ドリルパーツ。

  1. 原型の用意: Cylinder または Hex Prism を追加します。
  2. Deform 1: 先細り（Taper）の追加: サイドパネルの 13. Deform (Stack) から Add Deform: Taper を選び、Taper Factor を調整して上端に向かって鋭角に細くします。
  3. Deform 2: ねじれ回転（Twist）の重ねがけ: 続いて Add Deform: Twist を追加し、Twist Angle を大きく設定すると、軸に沿ってドリル状に激しくねじれます。
  4. Deform 3: 全体の曲げ（Bend）の適用: さらに Add Deform: Bend を追加し、Bend Curvature を調整して角全体を三日月状に大きく湾曲させます。
  5. 非破壊編集の確認: 3つの変形はすべてスタックとして保持されているため、後から元の形状パラメータやねじれ角度だけをいつでも微調整できます。

パターン9: 【イテレーション＆プロダクション確定】Snapshotマテリアル分離とFinalize

目的: 試行錯誤の過程で複数のデザインバリエーション（案A・案B）を安全にフリーズ保存し、最終的にゲームエンジンや3Dプリント用の通常メッシュとして安全に確定出力する。
想定成果物: 互いに干渉しないカラーバリエーション保存モデルと、クリーンな確定メッシュ。

  1. デザイン案Aの制作とスナップショット保存: ライブツリー上で形状を作り込み、マテリアル色をレッドに設定します。7. Finalize / Output の Snapshot Mesh ボタンをクリックすると、ライブ編集環境を維持したまま静的な確定メッシュが複製生成されます。
  2. ★V17.0.1 の安全仕様: 案Bへの移行とカラー独立性の確認: ライブツリーに戻り、形状を変更してマテリアル色をブルーに変えて「案B」を作ります。V17.0.1ではマテリアル自体が独立複製されているため、案Aは赤い色のまま完全に保持されます。案Aと案Bを並べて安全に比較検討できます。
  3. 法線シェーディングの仕上げ（Fix Normals）: 最終案が決定したら、確定前に Fix Normals ボタンをクリックします。SDFの数学的勾配から計算された高品質法線が頂点に書き込まれ、ポリゴン境界のシェーディング乱れが完璧に解消されます。
  4. プロダクション確定（Finalize / Bake All）: Finalize (Bake All) ボタンをクリックします。ライブ結果メッシュがBlender標準メッシュとして確定され、元プリミティブ群は自動的に非表示の履歴コレクションへ退避されます。通常のBlenderスカルプトやエクスポートへスムーズに移行できます。

制作フェーズ別 クイックチェックリスト

フェーズチェック項目推奨アクション
造形初期画面が重く感じないか？Output & Quality の Preset を Low または Medium にしておく。
形状結合時接合部が不自然に溶けすぎていないか？マゼンタ矢印ギズモで Smoothness を絞るか、必要に応じて Collection Divider を挟む。
ハードサーフェス時角が丸まりすぎて機械感が出ていないか？ビューポート上のボタンで Edge Profile を Chamfer または Tight に切り替える。
パーツ近接時別パーツとして並べたいのに溶け合ってしまうAdd SDF Tree で別ツリーにし、Tree Reference で配置する。
確定前シェーディングに違和感がないか？Fix Normals を実行し、法線ベクトルを最高品質に更新する。
試作保存時過去の試作案の色が巻き込まれて変化しないか？V17.0.1対応済み。安心して Snapshot Mesh を活用可能。
